## F-08. 월간 최적화 인사이트 보고

| 구분 | 케이스 | 조건 | 기대 결과 |
|------|--------|------|-----------|
| 정상 | 월간 보고 성공 | 전월 daily anomaly 결과 존재, Dify 정상 응답 | `output/monthly/yyyy-MM.dat` 저장 |
| 정상 | 해당 월 daily 결과 없음 | `output/daily/anomaly/`에 해당 월 파일 0건 | Dify 호출 스킵, 정상 종료 |
| 예외 | 사전 조건 위반 — daily anomaly 폴더 없음 | `output/daily/anomaly/` 자체가 없음 | 경고 로그 후 정상 종료(파일 없음과 동일 처리) |
| 예외 | Dify API 실패 | 호출 오류 또는 타임아웃 | 재시도 N회 후 배치 중단 |
| 예외 | 응답 스키마 불일치 | `monthly_report_result` 누락 | `ResponseMappingException`, 배치 중단 |
| 미해결 | daily_results_json 10MB 초과 | 전월 daily 파일 총량이 큰 경우 | 청킹 처리 미구현 — 그대로 전송(실패 가능성), `5_monthly-monitor-design.md` 4절 참고 |

**웹 화면 1회성 실행(기준시간 지정)** — `5_monthly-monitor-design.md` 5절 참고:

| 구분 | 케이스 | 조건 | 기대 결과 |
|------|--------|------|-----------|
| 정상 | 기준일까지 백필 후 월간 실행 | 기준시간 선택 후 "실행" | 기준월 1일~기준일까지 날짜별 1시간/1일 배치 백필 후 그 연월로 월간 배치 실행 |
| 예외 | 기준시간 파싱 실패 | 형식이 맞지 않는 값 | 백필 건너뛰고 스케쥴 실행과 동일하게(전월 기준) 처리 |
| 예외 | 특정 날짜 백필 실패 | 그 날짜의 시간대별/일일 배치 중 일부 실패 | 해당 날짜만 격리, 나머지 날짜와 월간 배치는 계속 진행 |
